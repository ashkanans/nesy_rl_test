\section{Experimental Setup}

\subsection{Benchmark and Run Scope}
This version reports only the completed \textbf{ColourBomb (CB)} experiments available under \texttt{runs/cb}. We focus on the alpha-sensitivity blocks:
\begin{itemize}
\item \texttt{runs/cb/alpha\_sens\_avoid\_bombs\_greedy\_s\{0,1,2\}}
\item \texttt{runs/cb/alpha\_sens\_reach\_goal\_while\_safe\_greedy\_s\{0,1,2\}}
\end{itemize}

CB is a gridworld with bombs (hazards), walls (blocked cells), start state, and multiple terminal goal cells. Episodes are finite-horizon, with per-step penalty, positive terminal goal reward, and negative terminal bomb reward.

\begin{figure}[t]
\centering
\includegraphics[width=0.72\linewidth]{figures/colourbomb/cb_environment_layout.png}
\caption{ColourBomb environment structure. Bomb cells are hazards, walls are non-traversable, and reaching any goal terminal ends the episode.}
\label{fig:cb_env_layout}
\end{figure}

\subsection{Specifications}
We evaluate two named presets that are available in the executed runs:
\begin{itemize}
\item \texttt{avoid\_bombs}: invariant safety ($G(\neg \texttt{bomb})$)
\item \texttt{reach\_goal\_while\_safe}: reachability with safety ($F(\texttt{goal}) \wedge G(\neg \texttt{bomb})$)
\end{itemize}

\subsection{Methods and Hyperparameters}
We compare TT variants with greedy decoding:
\begin{itemize}
\item \textbf{Vanilla TT}: \texttt{alpha=0.0}
\item \textbf{Logic-regularized TT}: \texttt{alpha} in $\{0.01, 0.05, 0.1, 0.2, 0.4\}$
\end{itemize}
All reported values are aggregated over seeds $\{0,1,2\}$ from the completed runs.

\subsection{Metrics and Aggregation}
For each run directory we read \texttt{baseline\_metrics.csv}. Primary metrics are:
\texttt{return\_mean}, \texttt{satisfaction\_rate}, \texttt{violation\_rate}, \texttt{goal\_rate}, and \texttt{bomb\_hit\_rate}.
We then aggregate by (spec, baseline) using mean and standard deviation across the three seeds.

To ensure reproducibility of figures/tables in this section, we provide a deterministic post-processing script: \texttt{build\_cb\_figures.py} (under \texttt{paper/scripts}).
It writes:
\begin{itemize}
\item seed-level and aggregated CSVs under \texttt{paper/tables/colourbomb}
\item figure PNGs under \texttt{paper/figures/colourbomb}
\end{itemize}
